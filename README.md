# MineSweeper 💣🧩

## C++ Console-Based Game

A console-based implementation of the classic **MineSweeper** game developed in **C++**. This game replicates the core mechanics of Minesweeper, featuring bomb placement, number hints, flagging, and a simple text-based interface for player interaction.

### 🚀 Features:
- **Random Bomb Placement**: Bombs are randomly distributed on the grid.
- **Uncovering Mechanism**: Recursive uncovering of cells.
- **Flagging**: Users can flag cells they suspect contain bombs.
- **Game Over/Win Detection**: The game ends if the user hits a bomb or uncovers all safe cells.

### 🛠 Technologies:
- **Language**: C++
- **Libraries**: Standard C++ libraries like `iostream`, `cstdlib`, and `ctime`.

### 📁 File Structure:
- `main.cpp`: The main driver file containing game logic and UI.
